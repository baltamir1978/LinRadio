# LinRadio

Radio por internet con carátula, letra sincronizada, historial con favoritas y reconocimiento de canciones.

Versión para Linux de [MacRadio](https://github.com/baltamir1978/MacRadio), la app de macOS. No es un port:
se escribe desde cero, con la app original como especificación.

**Estado: sin empezar** (21-oct-2026).

## Pila

Python 3 + GTK 4 + libadwaita, para **Debian 13 con GNOME**. Se instala con un paquete `.deb`.
